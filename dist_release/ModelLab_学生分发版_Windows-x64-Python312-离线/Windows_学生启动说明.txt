ModelLab 数学规划建模平台 · 学生使用说明（Windows / Mac 通用）
概要：首次安装、日常启动，以及如何用内置生产计划检查网页求解。

一、启动前准备
1. 请先将整个压缩包完整解压到任意本地文件夹（不要在压缩包内直接双击运行）。
2. 此包不含 Python 本体。请事先安装 Windows x64 的 64 位 CPython 3.12（python.org 的 Windows installer (64-bit)）。模型求解在本机进行。
3. 首次使用（Windows）：
   - 先双击运行 `安装依赖.bat`。安装器会复用项目的 `.venv`，保留已满足要求的依赖，并优先使用随包的 `wheelhouse`（包含 HiGHS）；只有本地无法完成安装时才会尝试从 PyPI 下载。
   - Windows x64 / CPython 3.12 所需的依赖已随包提供。若要明确禁止联网回退，请在解压目录打开命令提示符，运行 `安装依赖.bat --offline`。
   - 其他 Python 版本（脚本接受 3.10 及以上）或非 x64 环境只会尝试兼容的本地 wheels；依赖不全时通常需要联网，且不保证所有版本和架构都可安装。
   - 如果你在 Mac 上使用，可按 README.md 的 macOS 步骤创建虚拟环境并安装依赖。

二、启动方法
- Windows：双击 `start_windows.bat`，浏览器会自动打开 http://127.0.0.1:8000/ 。
- Mac：在项目目录的终端执行 `bash start_mac.command`。
- 通用（Spyder / PyCharm / VS Code）：
  直接用 IDE 打开项目文件夹中的 `main.py` 并点击运行（Run / F5）。

使用期间请保持黑色命令行窗口（或 IDE 控制台）运行；结束使用时关闭窗口或按 Ctrl+C（在 Spyder 中点红色停止按钮）。
首次使用可以打开“参考案例”，复制“生产计划 · 整数决策”，核对并确认模型后点击“运行已确认模型”。结果页应显示最优目标值 10。

三、功能与求解器说明
1. 内置求解器：平台自带开源 HiGHS 求解器，无需额外安装即可求解 LP / MILP 模型。
2. 商业求解器（可选）：如需使用 Gurobi 或 CPLEX，请在运行 ModelLab 的 Python 环境中配置对应的软件包及许可证。
3. 大模型辅助（可选）：进入左侧“模型设置”配置服务，即可使用 AI 生成模型草稿、诊断及解读结果。连接设置保存在本机；调用云端模型时，相关输入会发送给所选服务。
