# 实施决策与规格差异

**2026-11-17 本机求解更新：用户明确要求无需 Docker，当前默认执行方式改为独立本机子进程；Docker 保留为可选模式。见 [本机求解](LOCAL_SOLVER.md)。本文历史条目的 Docker-only 限制已被新要求替代。**

**2026-11-17 更新：用户将产品改为免登录的个人学习科研工作台，当前行为以 [个人版调整](PERSONAL_MODE.md) 为准。下列课程/角色/账号条目记录原 M1–M3 的历史决策，已被个人版要求替代。**

范围：用户授权 M1–M3。独立诊断、建议 patch、诊断开关及 M4 课堂收尾不在本次交付范围；对应诊断 API 未开放。

1. **独立目录**：应用位于 `modellab/`，原始资料和参考项目保持原样；没有复制上游代码。
2. **存储**：使用 Python 标准库 sqlite3、参数化 SQL、显式事务与 WAL，替代推荐的 SQLAlchemy。初版实体固定，避免引入无实际作用的 ORM；迁移脚本为 `backend/migrations/001_initial.sql`。当前仅有初始迁移；后续结构变更必须新增迁移，不能覆盖已有库。
3. **环境**：在本机安装了项目内 uv 与 Node，uv 管理 Python 3.12。没有安装/启动 Docker Desktop，也没有配置新的付费服务。本机真实 Docker 与真实 LLM 测试因此跳过；线上求解接口严格返回不可用，不以宿主执行回退。M1 本地 CLI 是用户主动运行可信模型的独立开发工具。
4. **历史版本**：历史确认与运行可查看、导出；发起新求解、识别或编译只允许当前版本。重跑历史模型时复制为新草稿并再次确认。
5. **确认 hash**：保守地包含完整模型、题意、实例数据、图片顺序/旋转；展示文字变动也需重新确认。比规格允许的仅语义变化失效更严格。初版不实现展示样式免确认优化。
6. **公式编辑**：采用受限文本语法（`3*x+5*y`、`sum(i,I,x[i])`）→ Python `ast.parse` → 显式白名单 → 平台 AST；没有 eval/exec/sympify。任意 LaTeX 仅能作为转录展示，暂不承诺重新解析为数学语义。用户可以编辑公式文本、符号表和高级 AST；每次解析须预览应用。
7. **缺失范围**：草稿可保存未声明的上下界；确认时拒绝。null 显式表示自由方向。UI 新变量不会自动补非负。
8. **边界语义**：v0.1 变量上下界为标量；索引变量共享上下界。不同索引成员的界限可以写成带量词的线性约束，不做参数化上下界快捷语法。
9. **参数数据**：数组使用 `{indices:[...],value:...}` 的完整条目列表，保证整数/字符串成员不混淆；可显式声明 default。CSV/Excel 未实现。
10. **图片处理**：原图不覆盖；版本记录顺序与 0/90/180/270° 旋转。provider 发送旋转后缩放副本，归一化 bbox 逆变换回原图；无法定位保留整页来源。附加 2500 万像素解码上限。
11. **LLM 协议**：可配置 Chat Completions 图像 adapter；MODEL_VISION 与 MODEL_JSON_MODE 必须由管理员确认。健康检查表示配置与 worker 可用性，不冒充远端能力探测或识别准确率。只对输出结构错误有限重试（最多两次），HTTP/网络错误不自动重试收费调用。
12. **资源**：求解限时默认 30 秒、API 上限 120 秒；容器 1 CPU / 1 GiB / 64 pids；墙钟多 10 秒。基础资源配置集中在 dispatcher；本阶段未做教师资源配置界面。全局 AST/模型限额在 Limits 中。
13. **会话**：使用随机 256-bit 不透明 token，数据库只保存 token hash；不使用签名 cookie，因此不需要空置的 SESSION_SECRET。HttpOnly、SameSite、CSRF token、Origin 检查与登录限流均已实现。
14. **复现**：导出代码与实际执行同一个固定模板；源映射指向模板末尾生成的公式/实例注释和 IR 位置。实例不为每一行动态生成 Python 语句。离线复现要求环境已经安装锁定依赖。
15. **启动**：`make start` 同时运行 API/worker并提供构建后的前端；开发模式可用三个终端。所有监听默认 127.0.0.1。没有执行外部部署。
16. **并发与规模**：默认两路 solver 加一路识别；只允许一个 dispatcher。未做整班负载基准，不承诺高并发性能。
17. **截止时间**：记录 UTC，界面按 Asia/Shanghai 显示；当前作为教学提示显示，不禁止截止后练习或修改。
