# 个人版调整 · 2026-11-17

本轮用户要求替代原课程产品定位：免登录、无角色区分、界面配置模型连接、参考案例库。

## 变更

- 删除登录页面、登录 API、课程/成员/作业管理 API 和账号初始化命令。
- 打开页面自动建立本机工作台连接；仍保留 HttpOnly/SameSite cookie、CSRF、Origin/Host 检查以防外部网页调用本地接口，用户无需操作账号。
- 所有既有本地模型项目在个人工作台中可访问、编辑，原图、版本、确认和审计不删除。数据库保留旧表和关联；内部固定 actor 仅为兼容旧外键，不是产品账号或权限角色。
- 增加“模型设置”：云端兼容接口 / 本机服务、API 地址、模型名、API Key、图像输入与 JSON 模式。支持保存、替换密钥、清除、文本连接测试。
- 配置以原子写入保存到本机 0600 文件。读取接口仅返回 key_configured，不回传密钥。worker 每次任务读取配置，保存后不需重启。
- 不同 API 地址不能隐式沿用原密钥。排队期间设置发生变化会要求重新提交。
- 六个内置案例可预览模型和数据、创建可编辑副本，始终从未确认状态开始。
- 个人模式是同一台机器上的单工作台，不包含公开部署或多人隔离功能。

## 验证

- 后端：51 项通过；3 项因 Docker/真实 LLM 凭据缺失跳过。
- 前端：TypeScript 检查与生产构建通过。
- 浏览器：1 项端到端测试通过（7.12 秒）。真实 Chrome + API + 临时数据库；检查免登录进入、模型设置保存/刷新/清除且密钥不回显、六个案例预览和导入、原有编辑/确认/导出/模拟识别/历史流程。
- API 新增回归：旧模型继续可编辑；案例可编译；设置持久化与 0600 权限；密钥不出现在响应/异常/ZIP；改变地址拒绝隐式复用密钥；模型 adapter 读取界面配置并正确发送图像与鉴权头；配置过期保护。
- 模型网络请求使用 MockTransport 验证协议与错误处理；没有将真实凭据发送至外部服务，没有声称真实识别准确率。
